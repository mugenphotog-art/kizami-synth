# KIZAMI Synth

A local, AI-assisted synthesizer for Windows by Mugen Works. All sound and AI processing run on your own PC.

This repository only hosts the installer. Download the setup file from the Releases page (latest release), then run it. The SHA-256 of each installer is listed in the release notes, so you can check the download.

## Windows SmartScreen

The installer is not code-signed yet, so Windows SmartScreen may show Windows protected your PC. Click More info, then Run anyway.

## Free and Pro

The app starts in Free mode. Pro features are unlocked with a license key you receive after purchase.
